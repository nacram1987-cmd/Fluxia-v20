🔧 Troubleshooting
════════════════════════════════════════════════════════════════════

¿La app no carga?
→ Limpia cache (Ctrl+Shift+Del → selecciona todo → borrar)
→ Intenta en incógnito
→ Abre DevTools (F12) → Console → busca errores rojos

¿No aparece "Instalar" en el navegador?
→ Debe ser HTTPS (GitHub Pages lo es ✓)
→ Debe ser primera vez (no si ya instalada)
→ En Safari iPhone: Share → Add to Home Screen
→ En Chrome Android: Menu → Install (si aparece)

¿Datos no se sincronizan?
→ ¿Hay conexión? (puedes ver otro sitio web)
→ En Ajustes → Nube, ¿está conectado a Supabase?
→ ¿Es la primera carga? (demora ~2s)

¿Quiero volver a una versión anterior?
→ Aún no disponible (fix en v93.9)
→ Por ahora: importa backup desde Ayuda → Datos
