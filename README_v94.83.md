## Que cambia
1. Todo se guarda en la nube al momento (editar, borrar, marcar pagado, cargos).
2. Tras login se reconecta la nube (imprescindible tras reinstalacion).
3. Colores del selector de mes armonizados con el fondo azulado (sin marron/violeta).

## Importante para la prueba de desinstalar
1. Debes tener sesion de nube activa (Ajustes → Gestionar nube → Entrar).
2. Marca / edita / borra algo.
3. Espera a ver el indicador de sync o 2–3 s.
4. Desinstala → reinstala → entra con el mismo email.
5. Los datos deben estar.
