# Fluxia Élite BETA v2.0.28-LAB

Esta versión corrige el Disponible de Élite para aplicar la misma regla que el HTML estable: los rescates y reposiciones de hucha permanecen en el historial, con impacto contable cero en Disponible. Las pensiones pendientes se excluyen.

## Verificación

Ejecutar desde la raíz del repositorio:

```sh
node lab/qa/elite-reconciliation-v2025.cjs
```

La conciliación real sigue pendiente de comparar un corte idéntico HTML/nube para el perfil y de resolver discrepancias de identidad de movimientos o vínculos de hucha. Los tests de esta suite son sintéticos. Esta entrega no altera datos de Supabase ni el HTML/PWA estable.
