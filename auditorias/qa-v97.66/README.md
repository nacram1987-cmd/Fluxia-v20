# Regresión permanente de Gastos variables

Desde este directorio: `npm install` y `npm test` (Node 22). No modifica los HTML, datos de usuario ni servidores: ejecuta la app en JSDOM con fetch bloqueado, almacenamiento efímero y movimientos sintéticos.

Compara el código con `../../v97.65.html` y verifica que solo desaparece el render legacy del Disponible. Comprueba totales propios, ambas vistas, cambio de mes, tarjetas, menú/logo, tareas diferidas, caché de navegación e invariantes financieros y bancarios. Mantener esta prueba en futuras versiones, adaptando la comparación de base solo cuando un cambio explícito lo justifique.
