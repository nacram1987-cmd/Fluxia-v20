## CAMBIOS RESPECTO A v94.9.2

### 1. PROBLEMA: Borrados que reaparecen
**Error:** Gasto fijo borrado, se reinicia, reaparece.  
**Causa:** Borrados no se sincronizaban; blacklist no era CRÍTICA.  
**Solución:** `planRescate_v2_borrados_blacklist` → array CRITICAS  
**Código:**
```javascript
var CRITICAS = [
  'planRescate_v2_provisiones',
  'planRescate_v2_borrados_blacklist',  // ← NUEVA
  'planRescate_v2_movimientos',
  // ... resto
];
```

### 2. PROBLEMA: Layout Dashboard desorganizado
**Error:** Mes selector + disponible sin alineación.  
**Causa:** Flexbox sin ordenamiento.  
**Solución:** `flex-direction: column` + `align-items: center` en fx-dashboard67  
**CSS:**
```css
.fx-dashboard67 {
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 8px;
}
```

### 3. PROBLEMA: Color mes en otras pestañas inconsistente
**Error:** Meses con oro claro, difícil de leer.  
**Causa:** Color heredado de CSS viejo.  
**Solución:** `.panel .sec-mes { background: #E6D4A0; color: #6B4A00; }`  
**Rango:** Dorado oscuro, 1.5x más visible que antes.

### 4. PROBLEMA: Scroll perdido al cambiar pestaña
**Error:** Cambias a Ingresos, estás en medio de la página, no ves el mes.  
**Causa:** No había scroll automático.  
**Solución:** MutationObserver en .active + window.scrollTo  
**JS:**
```javascript
var observer = new MutationObserver(function(mutations){
  for(var m of mutations){
    if(m.target.classList.contains('active')){
      window.scrollTo({top:0, behavior:'smooth'});
    }
  }
});
observer.observe(document.body, {attributes:true, subtree:true});
```
