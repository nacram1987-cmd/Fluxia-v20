# Fluxia v95.39 LAB

Versión de estabilización posterior a v95.38. Añade fecha real a los pagos de Huchas y reduce saltos/re-renderizado sin modificar el motor financiero.

## Prueba recomendada
1. Huchas → Usar dinero → Pagar su gasto.
2. Introducir importe, concepto y una fecha histórica.
3. Guardar y comprobar en Historial que aparece con esa fecha.
4. Cerrar/abrir y verificar persistencia cloud.
5. Navegar entre Dashboard/Huchas y observar que los estados de nube/toasts no desplazan la pantalla.
