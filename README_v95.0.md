# Fluxia v95.0-LAB

**Tu flujo de caja bajo control · Datos protegidos en nube**

---

## 🚀 Novedades v95.0

✅ **Borrados que no reaparecen**  
Ahora los gastos/ingresos que borras desaparecen para siempre, no vuelven al reiniciar.

✅ **Dashboard limpio**  
Mes centrado y disponible alineado. Visualmente mejor ordenado.

✅ **Meses en todas partes**  
Cambias de pestaña → el mes te acompaña en color oscuro bien visible.

✅ **Navegación suave**  
Al cambiar pestaña, subes automáticamente para ver el selector de mes.

---

## 📱 Cómo usar

1. **Abre:** https://nacram1987-cmd.github.io/Fluxia-v20/index.html?v=v95.0-LAB
2. **Cabecera:** Deberías ver "Versión v95.0-LAB"
3. **Prueba:** Ve a Ingresos → deberías ver el mes arriba en oro oscuro
4. **Nube:** Tus datos se sincronizan automáticamente con Supabase

---

## 🔐 Sincronización Supabase

- Automatizada: cada cambio sube a la nube
- Blacklist: los borrados se marcan y no vuelven
- Reconexión: si pierdes la red, reintentar automático
- Cifrado: contraseña separada de credenciales bancarias

## 🐛 Si algo falla

1. Abre DevTools (F12)
2. Ve a Application → Service Workers
3. Verifica que dice "v95.0-LAB"
4. Limpia cache (Ctrl+Shift+Delete)
5. Recarga página
