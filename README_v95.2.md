# Fluxia v95.2.3-LAB

**Lo borrado ya no vuelve · Meses a todo el ancho · Color por pestaña**

## Antes de subir
Descarga una copia de seguridad desde Ajustes.

## Subir a GitHub
Sube los 5 archivos: `index.html`, `index_fluxia_v95.2.3_LAB.html`, `fluxia-sw.js`, `fluxia-canal.json`, `manifest.webmanifest`.
Abre `https://nacram1987-cmd.github.io/Fluxia-v20/index.html?v=v95.2.3-LAB` y comprueba que la cabecera dice «Versión v95.2.3-LAB».

## Qué deberías ver
- Dashboard: mes, Disponible y los cuatro cuadros con el mismo ancho.
- Ingresos (verde azulado), Fijos (marrón), Provisiones (oro), Variables (violeta).
- Selector de mes igual en todas las pestañas.
- Ajustes → Cuenta y nube → «Dejar solo la nube en este dispositivo».

## Cómo comprobar los borrados
1. Borra un gasto, espera a ver «Guardado en nube», cierra la app del todo y ábrela. Debe seguir borrado.
2. Repite con un aporte de hucha y con el último elemento de una lista.
