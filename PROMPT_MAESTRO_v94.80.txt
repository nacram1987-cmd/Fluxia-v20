## NUEVA LEY v94.80 (UX CONSISTENCY)

### PRINCIPIO #26: SELECTOR DE MESES UNIFICADO EN TODAS LAS PESTAÑAS
**Razón:** v94.79 tenía selector solo en Dashboard. Cuando cambias de pestaña (Ingresos, Fijos, etc), desaparece el selector → confusión de usuario.

**Implementación v94.80:**
```html
<!-- En TODAS las pestañas -->
<div class="mes-selector-unificado" id="mesSelectUnificado" role="navigation" aria-label="Mes del plan">
  <!-- Se rellena con JS: 12 botones para Ene...Dic -->
</div>
```

**CSS:**
```css
.mes-selector-unificado {
  position: sticky;              /* Siempre visible */
  top: 0;
  z-index: 100;
  display: flex;
  gap: 8px;
  padding: 12px 14px;
  background: var(--surface);
  border-bottom: 1px solid var(--line);
  overflow-x: auto;              /* Scroll en mobile */
}

.mes-selector-unificado button {
  min-width: 72px;
  height: 40px;
  border: 1px solid #D4AF37;
  background: #F5F3EF;           /* Crema */
  color: #5C4033;
  border-radius: 8px;
  transition: all 0.2s ease;
}

.mes-selector-unificado button.active {
  background: linear-gradient(135deg, #8B6914 0%, #6B5312 100%);  /* Oro */
  color: #FFFFFF;
  border-color: #5C4010;
  box-shadow: 0 4px 12px rgba(139, 105, 20, 0.3);
}
```

**Ubicaciones:**
- ✅ Dashboard
- ✅ Ingresos
- ✅ Fijos
- ✅ Provisiones
- ✅ Variables
- ✅ Compartidos
- ✅ Huchas

**Color:** Oro #8B6914 → #6B5312 (prototipo B, consistente con resto)

**Scope:** MES GLOBAL (un solo mes para toda la app, no independiente por pestaña)

**Evento:** `fluxia-mes-cambio` con `detail: { mes: 0-11 }`
```javascript
window.addEventListener('fluxia-mes-cambio', e => {
  const mes = e.detail.mes;
  // Todas las pestañas escuchan → recargan datos del mes
});
```

**Verificación:**
1. Abre app
2. Ve a Ingresos → selector en top ✓
3. Cambia a Febrero
4. Ve a Fijos → sigue Febrero ✓
5. Ve a Provisiones → sigue Febrero ✓
6. Cambias a Marzo → TODAS muestran Marzo ✓
